# ♔ Responsive Web Chess App

HTML, CSS (Tailwind CSS), および JavaScript のみで構築された、モバイル・レスポンシブ対応のWebベースのチェスアプリケーションです。  
外部ライブラリを最小限に抑え、1ファイルの軽量設計でありながら、タイマー機能、PWA対応、PGNデータ入出力、音効・アニメーションなど豊富な機能を備えています。

---

## 主な機能

- **チェスルール完全準拠**
  - キャスリング、アンパッサン、ポーンのプロモーションモーダル対応。
  - ステイルメイト、50手ルール、スリーフォールド・レピティション（同一局面3回出現）、デッド・ポジションを自動判定。
- **UI / UX**
  - 駒のスライド移動アニメーション。
  - ライトモード / ダークモード 切り替え。
  - 座標表示 ON / OFF 機能。
  - 視点（盤面）の180度反転。
- **盤面拡大モード**
  - スマートフォンやタブレットを机に置いて対面で対局できる専用レイアウト。
  - 黒側の駒・タイマーが自動で180度反転表示。
- **チェスタイマー設定**
  - ブレット（3分）、ブリッツ（10分）、ラピッド（30分）、スタンダード（60分）、クラシカル（90分）。
  - 加算方式（フィッシャーモード / ディレイモード）にも対応。
- **対局管理・データ保存**
  - Web LocalStorage による自動セーブ・ロード機能（ページを閉じても中断した対局から再開可能）。
  - PGN (Portable Game Notation) フォーマットでのデータ出力（コピー）および読み込み（ロード）。
  - 終局後の対局リプレイ（一手ずつ戻る/進む・自動再生）機能。
  - プレイヤー名変更 ＆ 対局スコアボード（白勝数 / 黒勝数 / 引き分け数）。
- **効果音・バイブレーション ＆ PWA対応**
  - Web Audio API を用いた効果音（駒の移動・キャプチャ・チェック・キャスリング・終局音）。
  - モバイル端末用の振動フィードバック対応。
  - PWA (Progressive Web Apps) 対応で、ホーム画面への追加・オフライン動作が可能。

## 使い方 / 起動方法

ビルドツールやサーバー設定は不要です。

1. このリポジトリをクローンまたはZIPダウンロードします。
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   ```
2. `chess12_2.html`（または `index.html` にリネーム）を任意のWebブラウザで開くだけでプレイできます。

### GitHub Pages で公開する場合
リポジトリの `Settings` > `Pages` から、Sourceを `main` ブランチに設定するだけで、簡単にWebアプリとしてオンライン公開できます。

## 使用技術

- **HTML5 / CSS3 / JavaScript (ES6+)**
- **Tailwind CSS** (CDNリソース経由でスタイリング)
- **FontAwesome 6.4.0** (アイコン表示)
- **Web Audio API** (効果音合成生成)
- **Service Worker / Web Manifest** (PWA機能)
